# 🛡️ SafeRoute AI

실시간 보행로 안전 안내 가이드 AI

## 프로젝트 소개

보행자가 이동 중 만날 수 있는 장애물과 위험 요소를
안내하여 안전한 보행을 돕는 웹 기반 프로젝트입니다.

## 주요 기능

- 보행로 위험 유형 선택
- 위험도 표시
- 안전 안내 문장 출력
- 반응형 웹 디자인

## 기술 스택

- HTML
- CSS
- JavaScript

## 실행 방법

1. 저장소를 다운로드합니다.
2. index.html 파일을 실행합니다.
3. 위험 유형을 선택합니다.
4. 위험 분석하기 버튼을 누릅니다.

## 향후 개발

- 이미지 분류 AI 연결
- 실제 보행로 사진 분석
- 음성 안내 기능
- 안전 경로 추천
- 피지컬 디바이스 연동
